## 预连接（参考 TMallKey BleLockClient）

连接**不是常驻**的，按两条计时规则自动回收：

- **进入前台先自动预连接**（`onStart` → `client.setForeground(true)` + `client.preconnect(mac)`），
  建立 GATT 连接 + 开启通知但**不**进协议；**30s 内没有开锁就自动断开**（冷启动窗口）；
- **一旦开锁则保活 60s**，期间再开锁重新计时（`beginTask` / `endTask` + idle 计时）；
- **退到后台（含息屏）立即让出**（`onStop` → `setForeground(false)`；busy 时延后到任务结束）；
- **连接复用**：同地址已就绪则跳过扫描/连接/发现，直接进入协议（冷启动 ~1.2s → 再开 ~0.4s）。

实现：`DoorLockClient.java`（单例）——`isReady / isConnecting / getReadyAddress / setForeground /
beginTask / endTask / preconnect / unlock / queryBattery / getLastRssi / cancel` +
`ConnectionListener`。

## 一站式（登录 → 获取钥匙 → 解锁）

> 详细流程见 `unlock_app\一站式使用说明.md`。

把钥匙抓取做成全自动：**`unlock_module\build\out\doorunlock-sync-module.apk`** 是一个
LSPatch/Xposed 模块，注入官方天猫校园（`com.tmall.campus.and`）后 hook
`VocLockHelperV2.unlock(Context, JSBParams, UnlockCallback)`，从 `JSBParams` 直接抓
**已解密** 的 `macAddress + activationKey`（32 hex，每把锁固定，等价钥匙），落盘后经本地
回环 Socket（127.0.0.1:42742）或广播同步给本应用。

用户只需：**在补丁版天猫校园正常登录、点一次开锁** → 回本应用点「一键同步钥匙」（可选自动开锁）
→ 进入前台自动预连接 → 点圆形开锁按钮。此后完全离线、永久有效。

> 抓钥匙的完整三种方式（补丁版 / root 抓取 / 电脑 adb）与排障见 TMallKey 官网。

## 构建（命令行，无 Gradle）

脚本：`unlock_app\build.ps1`（PowerShell）；模块：`unlock_module\build_module.ps1`。

图标生成（可选，改图标时）：`unlock_app\make_icon.ps1`（WPF `DrawingVisual` +
`PushTransform(MatrixTransform)` 光栅化网上挂锁矢量，输出
`res\drawable\ic_launcher_foreground.png` + 全套 mipmap 方/圆）。

步骤（build.ps1 自动执行）：
1. `javac --release 8 -cp android.jar -d build\classes java\...`（**显式枚举源文件**）
2. `jar cf build\classes.jar -C build\classes .`
3. `java -cp android-sdk\build-tools\android-14\lib\r8-8.2.47.jar com.android.tools.r8.D8 --min-api 21 --output build\dex --lib android.jar build\classes.jar`
4. `aapt2 compile --dir <res> -o <flat>` → `aapt2 link -o app.apk -I <android-34.jar> --manifest AndroidManifest.xml --auto-add-overlay`
5. `jar uf app.apk classes.dex`（把 dex 加入 APK 根目录）
6. `zipalign -f 4 app.apk app.aligned.apk`
7. `apksigner sign --ks doorunlock.jks --out doorunlock.apk app.aligned.apk`

### 注意事项

- **javac 的 `*.java` 通配符展开在含空格路径会失败**（如 `E:\Opencode work`）——
  构建脚本用 `Get-ChildItem` 显式枚举源文件传入，勿改回通配符。
- **aapt2（native）无法 stat 含中文路径的 android.jar / res**，需用 ASCII 副本
  （构建脚本自动复制到 `C:\Users\ROG\AppData\Local\Temp\opencode\unlock_build_cache\`，
  缓存目录在工作区外）。javac/d8/apksigner（Java）不受影响。
- **必须使用稳定 R8**（`r8-8.2.47.jar`，已下载）。build-tools 自带的 `R8_8.2.2-dev`
  版本不稳定（曾导致 d8 生成错误 dex），勿替换。
- **签名**：debug keystore `unlock_app\build\doorunlock.jks`，首次构建自动生成；
  口令由环境变量 `DOORUNLOCK_KEYSTORE_PASS` 提供，不入库。覆盖安装需同签名。
- 产物在含中文路径下 `aapt2` 无法读取，验证 badging 时请先把 APK 复制到 ASCII 路径再 `aapt dump`。
