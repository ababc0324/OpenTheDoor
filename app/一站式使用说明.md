# 天猫校园门锁 — 一站式「登录 → 获取钥匙 → 解锁」

本方案把钥匙抓取做成**全自动**，你只需要：**在补丁版天猫校园里正常登录、点一次开锁**，
钥匙就永久同步进本应用，之后**完全离线、永久有效**。

## 原理

天猫校园点「开锁」时，H5 经 WindVane 桥把 **已解密** 的 `macAddress + activationKey`
传给 native：
```
VocLockHelperV2.unlock(Context, JSBParams, UnlockCallback)
```
门锁是**离线 BLE**，`activationKey` 是每把锁固定的 32 位 hex 钥匙，**不经过任何服务器校验**。
所以只要在这个调用点把钥匙抓出来，就能永久离线开锁——**无需服务器 API、无需
`voc_lock_secret_key`**（后者在阿里 SecurityGuard 里、绑定原 APK 签名，静态无法提取，也无需提取）。

`doorunlock-sync-module.apk` 是一个 **LSPatch / Xposed 模块**，注入官方天猫校园后：
- hook 上面 3 个 `unlock` 重载（`VocLockHelperV2` / `VocLockHelper` / `VocLockManager`，容错）；
- 抓到钥匙后**落盘**（跨进程重启仍在，只需解锁一次）；
- 提供本地回环 Socket `127.0.0.1:42742`（带 token）+ 广播 `io.github.ababc0324.openthedoor.ACTION_KEY`。

本应用（`doorunlock.apk`）的「**一键同步钥匙**」按钮连上该 Socket 把钥匙拉回来，
Keystore 加密落盘，勾选「同步后自动开锁」则直接解锁。

## 一次性准备（免 root）

**补丁包已打包好**，直接安装即可，无需自己打补丁：

- **补丁版天猫校园**：`unlock_module\build\out\天猫校园_5.8.0_补丁版.apk`
  （118.98 MB，SHA-256 `37b3eb107a34f0017231c344c9883e6c88d00f6766ab6c00babc8f31ae16e788`，
  已注入 `doorunlock-sync-module.apk`，包名仍为 `com.tmall.campus.and`，v5.8.0）
- 安装：把该 APK 弄到手机上（**USB 拷贝 / 云盘 / 微信传文件皆可，不需要 adb**），用文件管理器点安装
  （首次需允许「安装未知应用」）。**若已装有官方原版，需先卸载**（签名不同）。

### 官方天猫校园更新后，如何自己重打补丁

1. 下载官方天猫校园新版 APK（`com.tmall.campus.and`）。
2. 用 **JingMatrix/LSPatch v0.8**（官方 LSPosed/LSPatch v0.6 **没有** `-l` 签名伪装选项，
   打出的包阿里安全 SDK 一开就崩，**必须 v0.8**）：
   ```
   java -jar lspatch-v0.8.jar 天猫校园_新版.apk -m doorunlock-sync-module.apk -l 2 --force -o dist/
   # 产物是 dist/<原名>-439-lspatched.apk
   ```
   `lspatch-v0.8.jar` 已在 `unlock_module\build\lspatch-v0.8.jar`（SHA-256 `b81094ac...`）。

## 使用（一站式）

1. 安装 `doorunlock.apk`（独立开锁应用）。
2. 打开**补丁版**天猫校园 → 正常登录 → 进门锁页 → **点一次「开锁」**。
   （模块此时抓取钥匙并落盘；调试可 `adb logcat -s fkTM` 看 `captured`，但**调试才需要 adb**。）
3. 打开本应用 → 点「**一键同步钥匙**」→ 已勾选「同步后自动开锁」则直接解锁。
   - 若提示「未捕获到钥匙」：回补丁版再点一次开锁，然后重试。
4. 以后**完全离线**：打开本应用 → 点「开锁」即可，不再需要天猫校园、网络。

## 已 root 的更省事方案（无 PC / 无 adb / 无补丁）

如果你已 root，**完全不用打补丁、不用 PC、不用 adb**：

1. 安装 **LSPosed**（Zygisk）框架，并安装 `doorunlock-sync-module.apk` 作为普通模块，
   在 LSPosed 里勾选作用域 `com.tmall.campus.and`，重启。
2. 打开**官方原版**天猫校园 → 登录 → 门锁页 → **点一次「开锁」**（模块抓取钥匙并落盘）。
3. 打开本应用 → 点「**root 抓取钥匙**」（直接读模块落盘的文件）→ 勾选自动开锁则直接解锁。

之后同样完全离线、永久有效。

## 常见问题

- **补丁版一开就崩**：不是用 JingMatrix/LSPatch v0.8，或没用 `-l 2`。重打补丁。
- **开锁报错 status 133 / 偶发失败**：已加固（`DoorLockClient`）——连接后协商 MTU(247)
  使 UNLOCK 帧单包写入、写失败重试 3 次、writeType 按特征属性、请求高连接优先级。
  若仍偶发：靠近门锁、清空其它占用该锁的 App、多试几次（重试会自动进行）。
- **连接反复断开**：确认锁未被其它设备占用；关掉其它 BLE App；本应用已请求高连接优先级。
- **同步提示「连接失败」**：补丁版天猫校园进程没在运行（被杀了）。重新打开补丁版（钥匙已落盘，
  无需再点开锁）再同步；已 root 则直接用「root 抓取钥匙」。
- **「未捕获到钥匙」**：还没在补丁版/LSPosed 版点过一次开锁。点一次即可。
- **天猫校园更新后失效**：每次官方更新都要重新下载原版 APK、重新打补丁（模块不变；
  已 root + LSPosed 则无需重打）。
- **已 root 用户**：也可用 TmallKey →「+ 添加门锁凭证」→「root 抓取」，或
  `adb logcat -v time VocLockHelperV2:V '*:S'` 抓 `activationKey:` 后手动粘贴
  （后者**调试才需要 adb**，日常不需要）。

## 边界与风险

- 模块与补丁包**绑定 LSPatch v0.8**；重打包仍是修改别人 App，风险自担，出问题卸载后重装原版即可。
- `activationKey` 是这把门的钥匙，等价物理钥匙，**不要外泄**。
- 本模块只抓钥匙并同步，**不 hook / 不注入 / 不读取**天猫校园进程内其它数据，也不上传任何东西。
